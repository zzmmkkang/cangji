### 附：构建过程踩坑与解法（4 个坑，均已解决留痕）

| # | 坑 | 解法 |
|---|---|---|
| 1 | tauri 把 `.so` 软链进 jniLibs 报 `SymlinkNotAllowed`（无 SeCreateSymbolicLinkPrivilege、无开发者模式） | 静默提权开启开发者模式（本机 UAC=不提示即提权） |
| 2 | gradle wrapper 下载 10s 超时 + 直连仅 60KB/s | 腾讯镜像手动下载分发包 → 放入 wrapper 缓存目录并创建 `.ok` 标记（已从 wrapper jar 反查确认标记命名） |
| 3 | AGP 报 `project path contains non-ASCII characters`（`E:\仓库管理`） | 按 AGP 官方提示，写入**用户级** `~\.gradle\gradle.properties` 的 `android.overridePathCheck=true`（不碰生成物） |
| 4 | WiX 直连 GitHub 中断（重试一次仍失败） | `TAURI_BUNDLER_TOOLS_GITHUB_MIRROR` 指定镜像，哈希校验通过后 MSI 正常产出 |
