## 2. 契约遵守情况

**遵守**：目录结构（第 2 章）、8 页面 hash 路由（第 6 章）、24 命令清单与签名（第 4 章）、capabilities（1.5）、依赖清单（1.2/1.3）、CSP 与 identifier（1.4/第 2 章）。

**声明偏差**（逐条，均不影响 IPC JSON 契约形状）：

| # | 偏差 | 理由 |
|---|---|---|
| 1 | DTO 结构体暂放 src/commands/ 各域文件内（契约目录未单列 dto） | repo 层 A2 才填充；A2 可原地上移，前端类型不受影响 |
| 2 | single-instance 在 `setup()` 内注册而非链式 `.plugin()` | 该 crate 仅 desktop 存在，链式注册会破坏 Android 编译；Tauri 官方跨平台写法，防双开行为一致 |
| 3 | vite.config.ts 使用 `TAURI_ENV_*` 条件 build target | Tauri 2 官方模板标准写法 |
| 4 | Cargo.toml 增加 `[profile.release]`（lto/strip/opt-level=s） | 契约未规定；常规发布优化，A5 打包受益 |
| 5 | single-instance 依赖门控采用 `cfg(not(any(target_os="android", target_os="ios")))` | **编排者修复记录**：Cargo 依赖段不识别 tauri-build 注入的 `desktop` cfg（E0433），按官方文档改为按 OS 排除门控 |
| 6 | 空壳命令统一返回 `E_INTERNAL`「命令 X 尚未实现」 | A1 阶段占位语义，A2 全部替换为真实实现 |
